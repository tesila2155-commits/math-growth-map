# 数学能力生长与自主学习系统 V4.4

针对 V4.3 用户反馈进行的功能重构，不是视觉微调。

## 知识宇宙
- **点击五大知识群会实际展开**：上方地图自动放大定位，下方出现对应领域的全部知识星球清单，点击星球进一步查看连接、追踪其他领域知识、进入学习挑战。
- 所有知识节点和跨领域关联仍在同一张连续宇宙网络，未拆成孤立地图。
- 保留搜索、拖动、缩放、全景、连线过滤、标签开关；全景用聚合展示避免拥挤。
- 修复 SVG 星球点击被 pointer capture 截获的问题，普通点击直接进入事件委托。
- 依赖和关联类型仍是已有数据里的待审查关系，界面不把相关性伪装成严格因果前置。

## 成长页面
- 使用真实作答事件绘制最近最多14个有记录日期的独立完成次数折线图；它是活动记录，不是能力总分。
- 新增「以前的我 vs 现在的我」卡片：仅在同知识节点/能力、前后不同任务、早期需要提示或未独立、后期独立成功时展示；否则明确显示证据不足。
- 以「探索→独立完成→迁移应用→延迟复测」跨栏可视化展示已记录的证据；各阶段互不替代。
- 知识星球成长、我的发现、下一步挑战、默认折叠的完整档案，避免长页面。
- 保留原始练习事件、知识宇宙、训练流程、原本的本地档案和备份结构。

## 已验证与限制
- 两段内联 JavaScript 已通过语法解析；GitHub 文件回读成功。
- 启动沿用 DOMContentLoaded 机制，防止出现「正在打开你的数学地图」卡住的已知错误。
- **没有真实 Edge 浏览器完整回归测试**；上线前应验证五大星系点击、节点跳转、跨领域连接、成长图、证据对比、训练记录、备份恢复。
- 曲线使用独立作答事件次数，不能证明能力连续增长；没有可比证据时不会生成虚假的对比卡。
- 不增加在线 AI 后端，也不声称完成全部节点的30题候选题库。

## 本地使用
下载该分支 ZIP，解压后打开 `v44/index.html`。建议先在旧版导出学习档案；不同本地文件路径的浏览器存储行为不能保证相同，必要时手动导入。
