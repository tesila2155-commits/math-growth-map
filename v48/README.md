# 数学能力生长与自主学习系统 V4.8｜视觉探索手册

## 打开方式

将整个仓库 ZIP 解压，在 **Edge / Chrome** 打开 `v48/index.html`。页面内已经包含知识数据与训练引擎，无需服务器或登录。不要仅保存 HTML 的网页截图。

## 本轮改造

### 知识探索：星云封面 + 六种关系可视化（共 7 页）

1. **经典星云**：参考仓库早期 V4.1 的螺旋布局重新绘制星空层级，不沿用 V4.7 简化大圆簇。可以拖动、缩放、点选星球。
2. **知识生长树**：明确区分前置和条件性帮助，探索知识上游与下游。
3. **知识进化阶梯**：对比相关基础、当前与可能的后续；不是声称所有节点构成唯一必经链。
4. **知识地铁图**：五条领域线路、可点击站点，**紫色虚线只连接已有数据中的真实跨领域边**。
5. **知识关系网络**：聚焦当前知识的直接邻居，线条类型来自实际关系数据。
6. **知识变形实验室**：以乘法分配律为案例，拖动分割把手或滑块，实时更新面积与式子；其余知识尚未制作专属实验，界面明确说明。
7. **知识技能树**：节点点亮仅来自当前档案的既有练习证据，无任意锁死机制。

> 用户提及的“V2 星云图”原始设计文件未能在当前 GitHub 仓库找到。本版**恢复仓库可查的早期星空布局并精细化重绘**，不声称已经逐像素恢复未找到的 V2 文件。若后续取得原版截图/源文件，可再进行精确还原。

### 能力训练：六种不同场景（共 6 页）

跨栏赛道、能力进化树、挑战岛、思维变形实验室、迁移冒险地图、真实成长时间轴。跨栏栏位可点选并查看证据条件；挑战岛进入现有训练；实验室支持拖动方格组、旋转、重排；迁移地图进入关联知识；时间轴只用真实学习记录。

### 统一翻页体验

左右箭头、底部页码点、页内空白区域左右轻扫、桌面键盘方向键均支持翻页；支持“减少动画”系统设置。**翻页保留选中的知识点/能力对象**。可交互图形拖动区域不触发误翻页。

## 数据兼容与边界

- 延续 `math-growth-v4-students` 本地档案键、既有多档案/训练题库/学习记录；没有引入账号、家长端。
- 知识关系来自现有图谱草案，仍需要逐条教材与结构验证。“结构相似”不等于严格前置。
- 能力场景是学习活动的观察视角；不会通过装饰性跨栏/打卡虚构掌握程度。延迟复测、迁移必须由真实任务记录支持。
- 个别新场景是高保真交互示范，并非已经为 62 个知识节点逐一制作专属动画。没有适配时明确显示边界。
- `file://` 模式下不同浏览器或本机路径可能有不同的存储作用域。升级前建议从“我的档案”导出 JSON 备份。

## 交互验收

`v48/tests/smoke.mjs` 使用 Playwright 打开离线文件，遍历 7 个知识页和 6 个能力页，检查翻页与面积实验，并生成桌面/手机截图。对应 GitHub Actions 工作流位于 `.github/workflows/v48-visual-check.yml`。

本 README 不代替实际测试结果；以 GitHub Actions 最近一次运行的结论为准。
