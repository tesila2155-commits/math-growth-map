# 数学能力生长地图 V4.0 · 第一阶段

这是面向**小学生自主学习**的 V4.0 单文件可运行版本。保留原仓库已有的 `dist/` 主站，不覆盖旧版本。

- 运行入口：[V4.0 网页](index.html)。下载后在浏览器打开即可。
- GitHub Pages 发布入口：仓库启用 Pages 且发布工作流成功后访问 `https://tesila2155-commits.github.io/math-growth-map/v4/`。
- 对应发布目录：`dist/v4/index.html`（与此文件完全相同）。

## 第一阶段范围

- 知识与能力双入口，以及学生可以自由选择的今日推荐
- 12个能力方向的儿童概念启蒙：是什么、为什么学、体验小活动
- 5个首批知识节点（乘法分配律、分数、面积、平均数、数量关系建模）
- 每节点30道候选题的六阶段内部题目结构
- 结构对比、提示、学习记录、迁移与延迟复习提醒
- 本地多档案与数据导入导出

## 研究与质量边界

这是一阶段教学原型，并非经过学生实证验证的完整数学能力诊断产品。候选题需进一步完成逐题数学与教学审查。没有依据一次错误直接认定孩子某项能力缺失。

## 部署说明

现有 GitHub Actions 工作流部署仓库的 `dist/` 目录。当前如 Pages 未启用，需仓库所有者打开 **Settings → Pages**，将 **Build and deployment → Source** 设为 **GitHub Actions**，随后在 Actions 重新运行 `Publish math growth map` 工作流。
