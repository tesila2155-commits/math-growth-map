# 数学能力生长与自主学习系统 V4.3

## 本版目标
在不割裂跨知识联系的前提下，解决知识宇宙节点拥挤；将成长足迹从无限增长的长列表改成以真实学习证据为中心的精炼页面。

## 知识宇宙
- **同一张完整网络**，保留原有节点、跨模块边和关系类型，不拆成互不相连的子地图。
- 低缩放时显示五个知识群和跨群关联；放大后显示具体节点。
- 默认只突出选中星球的相关连接，按需可切换全图连线、显示全部标签。
- 支持拖动、滚轮/双指缩放、知识搜索定位、点击知识群放大、点击相关知识连续追踪。
- 关系标签保留“前置草案/条件帮助/关联”的审查语义，不将待验证关系冒充严格必要依赖。

## 我的成长
- 精简为成长摘要、独立/迁移/复测证据、最近成长时刻、我的发现、知识/能力切换与下一步目标。
- 不再默认渲染全部知识与能力赛道；各显示最多3项，完整档案手动展开且按12项逐步加载。
- 保留全部原始答题事件和本地备份，沿用 V4.2 存储键 `math-growth-v4-students`。
- 数字为实际记录计数，不作为统一能力总分；“从不会到会”的比较只在有足够可比证据时才能展示，暂未自动生成夸大的对比卡。

## 兼容与验证
- 旧版 `v41`、`v42` 文件未被覆盖。
- 两段内联 JS 已通过静态语法解析；GitHub 代码回读校验通过。
- 沿用此前修复的 DOMContentLoaded 启动机制。
- **尚未完成 Edge/Chrome/iOS 实机端到端交互测试**；需特别检查星系点击、平移缩放、节点聚焦、成长档案展开、练习和备份恢复。

## 使用
下载开发分支 ZIP，解压后在 Edge 或 Chrome 打开 `v43/index.html`。建议升级前在旧版“我的档案”导出备份。若同一电脑同一浏览器从 file:// 不同路径打开，存储可用性与隔离行为由浏览器决定，不保证自动读取旧版记录；必要时手动导入。
